# 🚗  Car Price Prediction

A machine learning project that predicts the price of a used car based on its features such as **year of purchase, kilometers driven, and fuel type**.  
The project is built with **Flask** for the backend and deployed on the cloud (Heroku / PythonAnywhere).

---

## 📌 Features
- Train a regression model to predict car prices
- Web interface for user input (Year, KM Driven, Fuel Type)
- Simple and clean HTML UI
- Flask-based backend
- Ready for deployment to cloud platforms
